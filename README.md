Welcome to my independent cybersecurity research repository. This space documents my hands-on enterprise lab setups, vulnerability assessments, and threat intelligence workflows used to analyze adversary behaviours.

* **Threat Simulation:** Simulating Active Directory exploitation, pass-the-hash attacks, and multi-stage network intrusions.

* **OSINT Frameworks:** Utilizing Shodan, Maltego, and advanced Google Dorking methodologies to track malicious infrastructure and domain spoofing activities.
